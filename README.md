# faxin-mcp（法信 MCP 连接器 · 公开版）

把[法信](https://www.faxin.cn)（法律出版社旗下的法律检索平台）封装成一个
MCP（Model Context Protocol）服务，让任何支持 MCP 的 AI 客户端
（Claude Desktop、Cherry Studio、各类 coding agent 等）都能直接检索
中国法律法规、裁判规则、法信大纲概念、类案（权威案例库）等。

**工作原理**：登录由你本人在弹出的浏览器中用**自己的法信官网账号**完成；
之后检索与详情读取都是带该会话 cookie 的纯 HTTP 调用。
登录态核验会单独打开检索页，检查浏览器实际可见的账号控件；成功结果缓存 30 分钟。
正文使用本地 HTML 解析，不通过浏览器渲染。原作者记录单次检索约 2-8 秒。

## 功能（9 个工具）

| 工具 | 用途 |
|---|---|
| `faxin_check_login` | 检查检索页中的明确账号标识（30 分钟缓存，`force=true` 强检；不代表所有库均有权限） |
| `faxin_search_law` | 法规检索（中央/地方，支持时效筛选：现行有效/失效/已被修改/尚未生效） |
| `faxin_search_case` | 裁判规则检索（法信编辑提炼的案例要旨） |
| `faxin_search_lib` | 专题库检索：国家条约 / 香港法律 / 澳门法律 / 法学期刊 / 法律释义 / 立法资料 / 司法文件 |
| `faxin_search_outline` | 法信大纲概念检索（法信码知识树，不知道用什么词搜时先做概念发现） |
| `faxin_get_outline` | 概念详情：聚合各库计数 + 相关法条摘录 |
| `faxin_get_tiao` | 法条直达：法规名（可简称）+ 条号 → 条文全文 + 效力信息 |
| `faxin_search_lalei` | 类案检索（权威案例库：指导性案例/公报案例/公布案例，支持案由、法院层级、省份、年份等筛选） |
| `faxin_get_detail` | 详情读取（法规/裁判规则/专题库条目全文，支持按条号精确取条） |

## 安装

建议使用 Python 3.12；本次回归验证使用 Python 3.12、MCP SDK 1.30.0、Playwright 1.64.1、lxml 6.1.3。

```bash
# 1. 克隆本仓库
git clone <repo-url>
cd faxin-mcp-public

# 2. 建虚拟环境并装依赖
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 3. 安装 Playwright 浏览器
.venv/bin/playwright install chromium
```

## 首次登录

```bash
.venv/bin/python login.py
```

- 弹出浏览器窗口 → 打开法信官网 → 点击「登录」→ 用**你本人的法信账号**完成登录
  （账号密码 / 短信验证码 / 扫码，以官网提供的登录方式为准）；
- 确认页面已显示登录状态后，回到终端按**回车**保存会话；
- 脚本会自动验证一次无头复用，只有验证成功才以退出码 0 结束；
- 会话过期时，先在 MCP 客户端中停止本服务，运行 `login.py` 完成登录，
  再启动本服务。同一浏览器用户目录不能被登录脚本和服务同时占用；
- 登录判断要求明确的账号标识。接口返回 200 或匿名计数 JSON 本身不证明已登录；
  核验使用浏览器的可见性判断，忽略隐藏字段、模板及 CSS 隐藏控件；
  无法识别页面结构时会报告“无法确认”，需要核对官网登录状态或适配页面。

**本脚本不会读取、记录或上传你的账号密码**——所有凭据只经过法信官网页面。

## 配置 MCP 客户端

以 Claude Desktop（`claude_desktop_config.json`）为例：

```json
{
  "mcpServers": {
    "faxin": {
      "type": "stdio",
      "command": "/你的路径/faxin-mcp-public/.venv/bin/python",
      "args": ["/你的路径/faxin-mcp-public/server.py"]
    }
  }
}
```

其他 MCP 客户端（Cherry Studio 等）同理：填 python 解释器路径 + server.py 路径即可。

### 可选环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `FAXIN_BASE_URL` | `https://www.faxin.cn` | 法信域名下的 HTTPS 入口；详情 URL 只能使用当前入口 |
| `FAXIN_USER_DATA_DIR` | `~/.faxin-mcp/browser-data` | 浏览器用户数据目录（存会话 cookie） |
| `FAXIN_HEADLESS` | `true` | server 端无头模式；调试时可设 `false` 看页面 |
| `FAXIN_MAX_RESULTS` | `20` | 检索默认返回条数 |

## 使用建议（关键词策略）

- 检索优先用**案由词**（如「买卖合同纠纷」「民间借贷纠纷」）或**法条原文表述**
  （如「盗窃公私财物」），抽象法律概念命中率低；
- 查法条：已知法规名+条号直接用 `faxin_get_tiao`（最快）；只知主题词用 `faxin_search_law`；
- 不知道用什么词搜时，先 `faxin_search_outline` 做概念发现，再按概念聚合的
  各库计数选库深挖；
- 裁判规则库较大，单次检索需 7-17 秒属正常；**请低频使用，不要高频连续调用**
  （平台会临时限速，冷却约 60 秒自愈）。

## 主站兼容性实测（2026-08-22，www.faxin.cn 匿名 + 登录态双轮探测）

以下为原作者在所示日期的历史记录，不代表当前账号或全部功能已重新验证。

**匿名可达（无需登录）：**

| 能力 | 接口 | 状态 |
|---|---|---|
| 首页/登录页 | `/`、`/login.aspx` | ✅ 登录表单含账号密码/短信/扫码 |
| 分库计数 | `GetLibSearchResultNum.ashx` | ✅ 返回 JSON `{"lib":..,"searchnum":..}` |
| 法规检索 | `GetFileInfoForZyfl.ashx` | ✅ 返回 `FirstHtml` 结果列表 |
| 法条直达 | `GetZyflTiaoInfo.ashx` | ✅ 返回条文全文+文号+效力信息 |
| 法规详情 | `ZyflContent.aspx?gid=` | ✅ 服务端直出全文 |

**登录后验证（个人法信账号实测）：**

| 能力 | 接口 | 登录态结果 |
|---|---|---|
| 登录态 | 检索页重定向 | ✅ 已登录不跳转（接口会话复用成功） |
| 大纲概念 | `GetKeyWordList.ashx` | ✅ 返回 `keywordhtml` 概念列表 |
| **裁判规则检索** | `GetFileInfoForAlyz.ashx` | ❌ 接口按关键词计数（AllCount 随词变化）但**结果列表为空**——该账号对裁判规则库**无内容权限**（能计数、不给看）。计数接口 `lib=alyz` 返回 `searchnum=0` 印证。**需账号购买裁判规则库权限** |
| 类案检索 | `wenshu.faxin.cn` | ⚠️ 首页 laIndex 链接 `token=` 为空，直接访问 `laIndex.html` 跳转 `wenshu/v2/#/index`（无 token）。**主站类案 token 生成机制与律协版不同，本工具在主站暂不支持类案检索**（待后续适配） |

**结论**：主站接口路径与律协 VIP 版**同构**。法规检索/法条直达/大纲/详情读取**登录后即可用**；裁判规则库受**账号权限**限制（与连接器无关）；类案检索因主站 token 机制差异**暂不支持**（律协版正常）。

```bash
python -m unittest discover -s tests -v
```

测试使用真实 MCP SDK，验证 stdio 握手、工具发现和错误标志；法信 HTTP 响应、
浏览器页面等外部依赖使用离线样例，不要求账号或下载 Chromium。
覆盖条号中的“零”和“条之一”、条文内交叉引用、长条文、并发详情、元数据、
登录误判、同源重定向及内网 URL 拦截。GitHub Actions 会自动运行这些测试。

本次还通过匿名 API 请求实际取得《民法典》第一百零一条，并读取了该法规详情中的
“现行有效”元数据。匿名 HTTP 页面未提供明确账号证据。最终的浏览器可见性核验、
登录和会话持久化仅有离线控件样例覆盖，仍需在用户环境实测；验证环境中 Chromium
下载失败，未使用真实账号，也未验证付费库权限。
之后一次匿名复测收到 HTTP 503，已被明确报告为接口错误；先前成功记录不代表接口持续可用。

主站 `faxin_search_lalei` 仍未适配，会返回明确的“不支持”错误，不再提示重新登录。
网络错误、接口限流和权限错误不应被视为“未找到”。详情使用本地 HTML 解析，
不执行页面脚本；按条提取要求行首条号后有空白或标题分隔符，以免把段落开头的条文引用
当作新条文。条号与正文无分隔且无法确定边界时，会保守地提示未能定位，需人工核对，
不会把可能相邻的两条作为一条返回。完整正文仍有长度上限，截断会明确标记。

公开的法信律协版服务协议对网络爬虫和自动下载程序有限制。个人账号、低频查询或
